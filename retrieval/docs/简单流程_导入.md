## 导入图（`app/process/tourism_import/agent/main_graph.py`）

```
node_entry.py ──┬─ md   → node_md_img.py ──────────────┐
                ├─ pdf  → node_pdf_to_md.py → node_md_img.py
                ├─ 表格 → node_tabular_parse.py ────────┤（跳过切分）
                └─ 文本  → node_text_parse.py → node_md_img.py
                                                        ↓
        node_document_split.py → node_tourism_meta_extract.py → node_bge_embedding.py → node_import_milvus.py
```
不支持的文件类型在 entry 直接抛错。

## 每个节点干什么

| 节点文件 | 背后服务 | 职责 |
|---|---|---|
| node_entry | entry_service.py | 收文件，按扩展名点亮四开关，条件路由选分支 |
| node_pdf_to_md | pdf_parse_service.py | PDF → Markdown，内嵌图片抽出落盘 |
| node_text_parse | text_parse_service.py | txt/json/html/docx → Markdown；docx/html 顺带抽内嵌图 |
| node_md_img | markdown_image_service.py | 增强 md 内嵌图（上传+图说）；无图安全早返回 |
| node_tabular_parse | tabular_parse_service.py | xlsx/csv 结构化解析（文旅专属，跳过切分直达元数据） |
| node_document_split | split_service.py | 按标题层级切分+细化为 chunks |
| node_tourism_meta_extract | tourism_meta_extract_service.py | LLM 抽内容类型（12 类）+ 专属字段 extra_meta |
| node_bge_embedding | embedding_service.py | BGE-M3 稠密+稀疏双路向量 |
| node_import_milvus | index_service.py | 写入 chunk 集合（tourism_chunks） |

导入图要点：**表格分支**（跳过切分直达元数据）、**元数据节点抽内容类型**。
