## 三、新增共享层模块的归属判定约定

1. **一律先放进 `app/shared`**，不要预判归属；
2. 若一个迭代周期后确认**仅单端引用**且另一端确无需求，再下沉到端目录
   （导入侧 → `app/process/*_import/`，查询侧 → `app/process/unified_query/`）；
3. 判定依据是**依赖图实测**，不是直觉：
   ```
   ./.venv/Scripts/python.exe logs/_tmp_t8_depgraph.py
   ```
4. 禁止"提前优化式"搬迁 —— 进程级隔离已满足部署需求，物理拆分只会增加 import 回归面。
