### T12 鉴权 / 限流

  （Redis `INCR`+`EXPIRE` 原子计数；不可用回落内存）。三档：用户 QPS / 用户日配额 / IP QPS。

  Mongo `users` 集合 upsert，未配凭据可用 `AUTH_MOCK_OPENID` 联调）+ WS 认证
  （首帧 / URL 参数 token）+ 查询前限流。
