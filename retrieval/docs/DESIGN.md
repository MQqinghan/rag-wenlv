# DESIGN.md — 文旅智能问答助手 项目汇报

> 场景：部门项目汇报（会议汇报，中密度）。受众为非技术人员。风格为通用设计路线（不命中学术/咨询/红金政务预设分支），结合项目「水墨文旅」产品气质原创推导。

## 1. 画布与全局母版（具体 px）

画布 1280×720。

| 母版区 | 位置 | 内容规则 |
| :--- | :--- | :--- |
| **A · 标题块** | y 0–120（上 padding 20，左右 padding 64） | 左侧：阶段标签 14px（主色，字距 2px，如「实现 · 核心能力」）+ 页面主标题 34px bold（文本色）；标题块右侧不放任何装饰小图 |
| **B · 内容区** | y 120–660（540px 可用） | 一切正文、图示、卡片；不挤占 A/C |
| **C · 页脚条** | y 660–720（下 padding 20） | 左：`文旅智能问答助手` 14px 灰（rgba 文本色 0.45）；右：页码 `NN / 10` 14px 灰。封面/结尾页省略 C 区 |

- 封面（P1）与结尾（P10）使用全幅图自定义版式，不受 A/B/C 约束。
- 内容页（P2–P9）严格复用同一母版结构，标题位置、页脚位置全篇一致。

## 2. 颜色系统（4 hex + rgba 变体）

| 角色 | 值 | 用途 |
| :--- | :--- | :--- |
| 背景（宣纸底） | `#FAF8F3` | 全页背景 |
| 主色（黛青） | `#2F6E63` | 标题栏底、大色块、编号大字、图表主系列、阶段标签 |
| 强调色（赭石） | `#B5542D` | 仅焦点元素：巨型数字、关键标注、印章式角标、"规划灯" |
| 文本色（墨青） | `#26302C` | 标题与正文 |
| 半透明变体 | `rgba(47,110,99,0.06~0.10)` 卡片底；`rgba(38,48,44,0.45)` 次要文字；`rgba(38,48,44,0.14)` 分隔线；图片蒙版 `rgba(20,32,28,0.40~0.55)` | 不引入新色相 |

- **渐变方案**：仅一处——主色标题栏/大色块用 `linear-gradient(135deg, rgba(47,110,99,0.95) 0%, rgba(47,110,99,0.72) 100%)`（同色透明渐变，不加新 hex）。
- **色彩面积分配**：主色 ≤ 60%（P4/P7 左栏为主色大面积页）；辅色逻辑由半透明变体承担 ≤ 30%；强调色 Supporting 页 ≤ 5%、Peak 页（P3/P9）≤ 15%；中性色（文本+宣纸底）为剩余。
- **色彩节奏**：P4、P7（左主色栏）与 P3、P9（强调色爆发）显著区别于其他页，满足"至少 2 页色彩比例显著不同"。

## 3. 字体系统（2 套家族）

| 层级 | 字体 | 字号/字重 | 行高 |
| :--- | :--- | :--- | :--- |
| 封面/结尾主标题 | 思源宋体（Source Han Serif SC） | 64px bold，字距 2px | 1.2 |
| 页面主标题（A 区） | 思源宋体 | 34px bold | 1.3 |
| 副标题/卡片小标题 | 思源黑体（Source Han Sans SC） | 22–24px bold | 1.4 |
| 正文 | 思源黑体 | 17–18px regular | 1.55 |
| 引文/例句气泡 | 思源黑体 | 16–17px | 1.5 |
| 巨型数字/锚点 | 思源宋体 | 72–120px bold | 1.0 |
| 阶段标签/页脚 | 思源黑体 | 14px | 1.4 |

- 标题用宋体（人文质感呼应水墨调性），正文用黑体（易读）；巨型数字用宋体加粗与正文区分。不使用系统默认无衬线兜底。

## 4. 信息密度基线

- 常规内容页（P2–P9）留白 ≤ 35%；每页 ≥ 1 个视觉锚点（≥ 48px 元素或 ≥ 30% B 区图示）。
- 卡片容器填充率 ≥ 85%；卡片尾部元素用 `marginTop:'auto'` 钉底；同行卡片标题/正文/尾段 y 轴对齐。
- 焦点锚点（巨型数字、大图、大色块）周围留白 ≥ 40px。
