# 文旅知识库项目实战需求说明
## 1. 项目背景
面向文旅平台场景，建设一个智能文旅知识库系统。系统需要接入景点信息、景区介绍、历史文化资料、文化知识介绍、游记攻略、推荐运营资料、游客评论摘要和常见问答等内容，并提供景点推荐、景点详情问答、行程场景推荐、文化知识问答和知识问答能力。

系统需注意：部分用户会先了解目的地文化再决定旅游行程，或单纯出于兴趣了解文化，因此文化知识介绍类内容（如地区文化特点、民俗风情、历史背景等）属于知识库的必要组成部分，即使问题表面上与旅游无直接关联（如"北欧文化有什么特点"），系统也应能基于知识库作答。

## 2. 项目目标与功能范围
**内容导入**
- 支持景点信息、景区介绍、历史文化资料、文化知识介绍、游记攻略、推荐运营资料、游客评论摘要和常见问答等内容导入，导入过程支持任务状态追踪与元数据管理（景点名、地区、内容类型、类别、来源文件名等）

**景点推荐**
- 可按景点名、地区、类别、游玩场景标签等条件查找，返回景点列表、景点特色、适合人群和推荐理由

**景点详情**
- 可查询景区介绍、历史文化背景、开放时间、门票信息、交通信息、游玩时长、内容标签和常见问题

**内容检索**
- 可定位景区资料、文化知识资料与游记攻略，返回景点名、地区、内容类型、文件名等来源信息

**文化知识问答**
- 可回答与地区文化、民俗风情、历史文化等相关的纯文化类问题（如"北欧文化有什么特点"），此类问题可能与具体景点无直接关联，系统应能基于文化知识介绍内容直接作答，并可在合适时关联相关地区或景点信息

**知识问答**
- 基于知识库内容生成答案，返回必要的引用信息

**交互能力**
- 支持单轮问答、多轮对话、流式输出和历史记录管理

**质量要求**
- 系统应具备基础异常处理能力，避免导入失败导致服务整体不可用；查询结果应尽量准确、可解释、可追溯，流式输出应具备较好的实时性；各模块应具备清晰分层，便于后续扩展

## 3. 角色说明
### 3.1 主要使用对象
- 游客：查询景区介绍、历史文化信息、文化知识介绍、游记攻略、推荐理由和常见问题；也可能单纯咨询文化类问题（不带有明确旅游意图）
- 内容运营：辅助整理景区资料、生成推荐内容、回答常见问题、快速检索知识点

### 3.2 协同角色
- 内容编辑：管理景区资料、上传文旅内容、校验知识库内容

## 4. 典型业务场景
### 4.1 景点推荐场景
当用户提出"有哪些适合亲子游的景点""推荐一个适合周末短途游的古镇"之类的问题时，系统应根据景区介绍、景点信息、推荐语、评论摘要等资料返回景点列表、景点特色、适合人群和推荐理由等内容。

### 4.2 景点详情场景
当用户指定某一景点时，系统应能够返回景区介绍、历史文化背景、开放时间、门票信息、交通信息、游玩时长、内容标签和常见问题等详细信息。

### 4.3 内容检索场景
当用户询问某个景区怎么玩、适合什么人群、有哪些必看要点或某个历史文化的解释时，系统应优先返回相关景区介绍、游记攻略、常见问答和评论摘要，并在需要时生成结构化回答。返回结果中应尽量包含景点名、地区、内容类型、文件名等来源信息。

### 4.4 游记攻略场景
当用户提出"故宫有哪些精彩游记"或"查询西安相关的旅行攻略"等问题时，系统应能定位到对应景点或生成攻略推荐，并返回攻略内容、评论摘要、推荐理由等。返回结果中应包含景点名、地区、内容类型等来源信息。

### 4.5 文化了解场景
当用户提出"北欧文化有什么特点""傣族有哪些传统习俗"之类看似与旅游无直接关联的文化问题时，系统应能基于知识库中的文化知识介绍、历史文化资料等内容直接返回文化特点、民俗风情、历史背景等结构化回答。此类场景下用户可能处于出行前的文化了解阶段，也可能只是单纯想了解文化，系统均应正常作答；在回答合适时可自然关联相关地区的景点或行程建议，但不应强行推荐旅游内容。返回结果中应包含地区、内容类型等来源信息。

## 5. 内容要求
知识库中的每条内容建议包含以下字段：

- 内容正文
- 内容类型：景点信息 / 景区介绍 / 文化知识介绍 / 游记攻略 / 推荐运营资料 / 游客评论摘要 / 常见问答 / 运营表格 / 线路推荐 / 酒店信息 / 美食推荐 / 交通指南（后 4 类为评审增强，与实际导入的线路/住宿/美食/交通类资料对齐）
- 景点名（景点相关内容）
- 地区（景点与文化知识内容均适用，文化知识可为国家/地区/民族等文化范围）
- 条目名称
- 类别/标签（自然风光/历史古迹/亲子/红色旅游/民俗文化/地域文化等）
- 文化主题（文化知识类型内容，如北欧文化、傣族习俗等）
- 游玩时长（景点类型内容）
- 来源文件名
- 来源路径或资源链接

## 6. 后续扩展方向
- 增加景区后台管理与知识库管理页面
- 增加文档增量更新能力
- 增加权限控制与多租户支持
- 增加个性化推荐、行程规划路径等文旅能力
- 增加导览图文检索能力，支持基于 OCR 文本或时间轴文本定位相关片段
- 导览检索结果可返回景点名、地区、开始时间、结束时间和片段摘要等信息
- 增加多模态检索，支持景区图片与内容联合检索
