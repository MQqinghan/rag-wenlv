## 统一查询图（`tourism_query/agent/main_graph.py`，编译产物 `unified_query_app` L239）

```
node_intent_route.py（意图路由：五层漏斗判域，规划句式另标 is_plan）
  │
  ├─ 闲聊 chitchat ──┬─ 纯时间问句 → node_datetime_answer（系统时钟直答，不联网不调 LLM）
  │                  ├─ 困惑澄清   → node_clarify
  │                  ├─ 指代不明   → node_chitchat_answer（确定性反问）
  │                  └─ 其余       → node_web_search_mcp → node_chitchat_answer
  │
  │        ├─ 有兜底答复 → node_answer_output_ab（直出，END）
  │        └─ 三路并行检索（有联网意图时追加联网）→ node_rrf
  │
  └─ 文旅 tourism → node_attraction_confirm（改写问题 + 抽取确认主体）
           ├─ 有澄清答复 → node_answer_output_tourism（直出，END）
           └─ 四路并行检索（恒定）＋ is_plan 时追加 node_tool_weather / node_tool_route
                              ↓
              node_rrf（同步屏障：多路候选 RRF 融合；天气/路线简报原样透传）
                              ↓
              node_rerank（全局精排：本地+网页统一打分，动态截断 + KB 保底席位）
                              ↓
              after_rerank 分发：
                ├─ 文旅 + is_plan → node_itinerary_generate（行程拼装）→ END
                ├─ 文旅           → node_answer_output_tourism → END
                └─ 闲聊           → node_chitchat_answer → END
```

关键编排（main_graph.py）：`route_by_domain` L90-104；`after_attraction_confirm` L148-159（is_plan 追加工具路 L157-158）；静态汇聚边 L195-204；`after_rerank` L208-215。

## 每个节点干什么

| 节点文件（nodes/ 下） | 背后服务 | 职责 |
|---|---|---|
| node_intent_route | tourism_query/intent_route_service.py | 判域漏斗（规则→追问继承→关键词→LLM 兜底），规划句式标 is_plan |
| node_datetime_answer | common/datetime_answer_service.py | "今天几号/星期几"系统时钟确定性直答，杜绝幻觉日期 |
| node_clarify | common/clarify_service.py | 困惑输入的澄清反问，不联网不走检索 |
| node_chitchat_answer | common/chitchat_answer_service.py | 闲聊/域外问题回答（联网结果+限定语收尾） |
| node_attraction_confirm | tourism_query/attraction_confirm_service.py | 一次 LLM 同时改写问题+抽取主体，tourism_entity 库确认（无主体降级全库检索） |
| node_search_embedding_tourism | 文旅 search_embedding_service.py | BGE-M3 稠密+稀疏 hybrid 向量检索（有主体按 item_name 过滤） |
| node_search_embedding_hyde_tourism | 文旅 search_embedding_hyde_service.py | 多改写+HyDE：一次 LLM 产 2 改写+1 假设答案，批量编码并发 3 路召回 |
| node_keyword_search_tourism | 文旅 search_keyword_service.py → common/bm25_service.py | 本地 BM25 倒排索引字面匹配（专有名词精确命中） |
| node_web_search_mcp | common/web_search_service.py | DashScope MCP 联网搜索（2.5s 超时熔断，失败降级为空） |
| node_tool_weather | tourism_query/weather_tool_service.py | 规划专属：LLM 解析目的地 → 和风定位+逐日预报 → 中文简报 |
| node_tool_route | tourism_query/route_tool_service.py | 规划专属：高德地理编码+驾车/公交规划，代码层算油费 |
| node_rrf | common/rrf_service.py | RRF 融合（k=60，只看排名不看原始分），同时是并行支路的同步屏障 |
| node_rerank | common/rerank_service.py | bge-reranker-large 统一精排；超长候选零 LLM 抽取式压缩；动态截断+KB 保底 |
| node_itinerary_generate | tourism_query/itinerary_service.py | 规划专属答案：KB 素材闸门 → 拼天气/路线/日期进专用模板 → 代码级后处理 |
| node_answer_output_tourism | 文旅 answer_output_service.py | 最终答案生成（流式 SSE）、出处标注、图片提取、历史落库 |

文旅图要点：**景点主体确认**节点、**规划专属三件套**（is_plan 分支 + 天气/路线工具 + 行程拼装）。
